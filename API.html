OpenAI-compatible API

Подключите AIHUB к своему AI-агенту

Используйте единый API для Codex и других клиентов, которые умеют работать с OpenAI-совместимыми Chat Completions и Responses.

Открыть настройки Посмотреть пример
Base URLAPI v1
https://aihub-site.github.io/aihub/api/v1
  • Bearer API-ключ
  • JSON-запросы и ответы
  • Доступ на тарифе Unlimited
01

Быстрый старт

Создайте ключ в настройках кабинета и передайте его в заголовке Authorization.

  1. 1
    Откройте настройки

    В личном кабинете найдите раздел API.

  2. 2
    Сгенерируйте ключ

    Скопируйте секрет сразу после выпуска.

  3. 3
    Укажите Base URL

    Вставьте адрес и ключ в настройках вашего агента.

cURL
curl https://aihub-site.github.io/aihub/api/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-sol","reasoning_effort":"high","messages":[{"role":"user","content":"Привет!"}]}'

Настройка AI-агента

Для клиента с поддержкой OpenAI-compatible API укажите эти значения в его настройках провайдера.

OPENAI_BASE_URLhttps://aihub-site.github.io/aihub/api/v1
OPENAI_API_KEYYOUR_API_KEY
02

Текстовые модели и режимы рассуждений

Передавайте model и reasoning_effort в запросах. API автоматически валидирует и применяет выбранную конфигурацию.

GPT-5.6 Solgpt-5.6-sol

Лучшая универсальная модель для кодинга, поиска ошибок и генерации текстов.

Режимы рассуждения:
auto low medium high
GPT-5.6 Terragpt-5.6-terra

Модель для сложных программных проектов, архитектуры и системной аналитики.

Режимы рассуждения:
auto low medium high
GPT-5.6 Lunagpt-5.6-luna

Скоростная модель для быстрых ежедневных задач и коротких рефакторингов.

Режимы рассуждения:
auto low medium high
Claude Opus 5claude-opus-5

Флагман Anthropic с высочайшим уровнем логики, математики и анализа кодовых баз.

Режимы рассуждения:
auto low medium high extra_high
Claude Fable 5claude-fable-5

Модель Anthropic для творческого программирования, документации и написания статей.

Режимы рассуждения:
auto low medium high extra_high
Claude Opus 4.8claude-opus-4.8

Проверенная аналитическая модель с высокой стабильностью при следовании длинным промптам.

Режимы рассуждения:
auto low medium high extra_high
Gemini 3.7 Flashgemini-3.7-flash

Сверхбыстрая модель Google с большим контекстным окном и высокой точностью ответов.

Режимы рассуждения:
auto low medium high
Gemini 3.6 Flashgemini-3.6-flash

Оптимизированная модель для мгновенных подсказок, автокомплита и ответов.

Режимы рассуждения:
auto low medium high
Gemini 3.1 Progemini-3.1-pro

Продвинутая модель для многошаговых задач, анализа данных и структурированного JSON.

Режимы рассуждения:
auto low medium high
low (fast / быстро)

Минимальное время отклика. Подходит для простых вопросов и генерации короткого кода.

medium (средний)

Оптимальный баланс между скоростью и глубиной проверки гипотез.

high (deep / глубоко)

Глубокое рассуждение и проверка краевых случаев перед выдачей ответа.

extra_high (max)

Усиленный режим сверхглубоких рассуждений (доступен для семейства Claude).

03

Инструкции для агентов и IDE

Выберите инструмент, откройте инструкцию и скопируйте готовые параметры подключения.

Добавьте провайдера AIHUB в %USERPROFILE%\.codex\config.toml, затем передайте ключ через переменную окружения.

Справка Codex
config.toml
model = "gpt-5.6-sol"
model_provider = "aihub"

[model_providers.aihub]
name = "AIHUB"
base_url = "https://aihub-site.github.io/aihub/api/v1"
env_key = "AIHUB_API_KEY"
wire_api = "responses"
PowerShell
$env:AIHUB_API_KEY = "YOUR_API_KEY"
codex

Откройте Cursor Settings → Models, вставьте ключ в поле OpenAI API Key и включите Override OpenAI Base URL.

Справка Cursor
  1. 1
    API Key

    Вставьте YOUR_API_KEY и нажмите Verify.

  2. 2
    Base URL

    Укажите https://aihub-site.github.io/aihub/api/v1.

  3. 3
    Модель

    Добавьте или выберите gpt-5.6-sol. Используйте режим чата; отдельные функции Cursor могут работать через его встроенные модели.

https://aihub-site.github.io/aihub/api/v1

Задайте адрес шлюза и токен в PowerShell. Claude Code сам добавит путь /v1/messages.

Справка Claude Code
PowerShell
$env:ANTHROPIC_BASE_URL = "https://aihub-site.github.io/aihub/api"
$env:ANTHROPIC_AUTH_TOKEN = "YOUR_API_KEY"
claude --model claude-opus-5

Для постоянной настройки те же переменные можно добавить в %USERPROFILE%\.claude\settings.json.

Установите Continue, откройте его локальный конфиг и сохраните этот блок в %USERPROFILE%\.continue\config.yaml.

Справка Continue
config.yaml
name: AIHUB
version: 1.0.0
schema: v1
models:
  - name: AIHUB GPT-5.6 Sol
    provider: openai
    model: gpt-5.6-sol
    apiBase: https://aihub-site.github.io/aihub/api/v1
    apiKey: YOUR_API_KEY
    useResponsesApi: false
    requestBody:
      reasoning_effort: high
    roles:
      - chat
      - edit
      - apply

Публичная документация Antigravity не описывает отдельное поле для произвольного OpenAI Base URL. Если сборка поддерживает VS Code-расширения, установите Continue и используйте конфиг ниже; иначе вызывайте API из терминала через cURL.

Справка Antigravity
config.yaml для Continue
name: AIHUB
version: 1.0.0
schema: v1
models:
  - name: AIHUB GPT-5.6 Sol
    provider: openai
    model: gpt-5.6-sol
    apiBase: https://aihub-site.github.io/aihub/api/v1
    apiKey: YOUR_API_KEY
    useResponsesApi: false
    requestBody:
      reasoning_effort: high
    roles:
      - chat
      - edit
      - apply

Для JetBrains установите Continue и используйте тот же config.yaml. В любом другом клиенте найдите настройки OpenAI-compatible provider и укажите три значения ниже.

Continue для IDE
.env / настройки провайдера
OPENAI_BASE_URL=https://aihub-site.github.io/aihub/api/v1
OPENAI_API_KEY=YOUR_API_KEY
OPENAI_MODEL=gpt-5.6-sol
OPENAI_REASONING_EFFORT=high

Подставьте ключ, выполните команду в терминале и получите JSON-ответ. На Windows можно использовать готовый вариант Invoke-RestMethod.

cURL
curl https://aihub-site.github.io/aihub/api/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-sol","reasoning_effort":"high","messages":[{"role":"user","content":"Привет!"}]}'
PowerShell
$headers = @{
  Authorization = "Bearer YOUR_API_KEY"
  "Content-Type" = "application/json"
}
$body = @{
  model = "gpt-5.6-sol"
  reasoning_effort = "high"
  messages = @(
    @{ role = "user"; content = "Привет!" }
  )
} | ConvertTo-Json -Depth 4

Invoke-RestMethod `
  -Uri "https://aihub-site.github.io/aihub/api/v1/chat/completions" `
  -Method Post `
  -Headers $headers `
  -Body $body
04

Методы API

Базовые методы для диалогов, Responses-клиентов, Claude Code и получения списка моделей.

POST/chat/completions

Chat Completions

Диалоговый формат с массивом messages.

POST/responses

Responses

Современный формат запросов для AI-агентов.

POST/messages

Messages

Anthropic-совместимый формат для Claude Code.

GET/models

Models

Список доступных идентификаторов моделей.

Обязательные заголовки

Передавайте ключ как Bearer-токен. Для POST-запросов используйте JSON.

Authorization: Bearer YOUR_API_KEYContent-Type: application/json
05

Ошибки доступа

API возвращает обычные HTTP-коды и объект error с понятным машинным кодом.

403

Нет Unlimited-подписки

Ключ остаётся действительным, но запросы не выполняются, пока у владельца нет активного тарифа Unlimited.

Перейти к настройкам
Ответ API
{
    "error": {
        "message": "Нет активной подписки. API работает только на тарифе Unlimited. Подключите Unlimited в личном кабинете.",
        "type": "subscription_error",
        "code": "unlimited_subscription_required"
    }
}
401

Неверный ключ

Ключ отсутствует или больше не действует.

403

Нужен Unlimited

Нет активного доступа к API.

429

Слишком часто

Превышена частота запросов.
